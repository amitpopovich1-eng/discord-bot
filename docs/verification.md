# אימות חשבון מיינקראפט (Hypixel)

הבוט לא מעניק רול מאומת על סמך שם שהוקלד. ההוכחה היא **קישור Discord בפרופיל ה-Hypixel**:

1. השחקן מגדיר ב-Hypixel את שם המשתמש שלו בדיסקורד. רק מי שמחובר לחשבון יכול לשנות זאת.
2. השחקן לוחץ על כפתור האימות ומקליד את שם המשתמש שלו במיינקראפט.
3. הבוט ממיר שם ל-UUID (Mojang), קורא את הפרופיל מ-Hypixel API, ומשווה את הערך ל-**שם המשתמש** (username) של מי שלחץ.
4. רק בהתאמה מלאה נוצר קישור, ניתן רול מאומת, וכינוי השרת משתנה לשם במשחק.

אין צורך בשרת מיינקראפט משלכם או בפלאגין. (גרסה קודמת של הפרויקט הייתה מבוססת פלאגין; היא נמצאת בהיסטוריית git בקומיט `8753e8c` למקרה שתקימו שרת בעתיד.)

## הגדרה

### 1. מפתח API של Hypixel
נרשמים בפורטל המפתחים של Hypixel (`developer.hypixel.net`) ומבקשים מפתח לפרויקט. לפי מה שמצאתי (**לא קראתי את הדף הרשמי**, כי הוא לא נגיש מסביבת הפיתוח שלי): חובה לרשום את הפרויקט, אסור לשתף או לקבע מפתח בקוד, ואסור להשתמש ב-API כ-proxy לאחרים. קראו את המדיניות הנוכחית בעצמכם, ובדקו אם מפתח פיתוח פג תוקף ואם צריך מפתח קבוע.

המפתח נכנס רק לקובץ `.env` (או למשתני הסביבה של הפריסה) בשם `HYPIXEL_API_KEY`. אל תדביקו אותו בצ׳אט, בקוד או ב-git.

### 2. בדיקת תקינות (חובה לפני העלאה)
הסקריפט הזה בודק מול השירותים **האמיתיים** את ההנחות שלא הצלחתי לאמת (פורמט האימות של המפתח, מבנה התשובה):

```bash
npm run check:hypixel -- <שם_במיינקראפט> [שם_משתמש_בדיסקורד]
```

הוא מדפיס אילו שלבים עברו, מה מופיע בשדה ה-Discord בפרופיל, ואם יש התאמה. הוא לא מדפיס את המפתח. אם הוא מדווח `auth` או `malformed`, **האימות לא יעבוד** ויש לתקן לפי התיעוד הרשמי לפני המשך.

### 3. בדיסקורד
```
/setup role feature:רול מאומת role:@Verified
/setup role feature:רול לא מאומת role:@Unverified
/setup channel feature:לוג מודרציה ואימותים channel:#mod-log
/verifypanel        (בערוץ #verify)
```
הסתירו את רוב הערוצים מ-@Unverified והראו רק את `#verify`. לבוט נדרשות ההרשאות Manage Roles ו-Manage Nicknames, והרול שלו חייב להיות מעל @Verified ו-@Unverified.

## מה השחקן עושה
פותח ב-Hypixel את הפרופיל ← Social Media ← Discord, ומקליד בצ׳אט את שם המשתמש שלו בדיסקורד (השם הייחודי, לא שם התצוגה). ממתין כדקה (ה-API עשוי להתעדכן באיחור), ולוחץ על הכפתור בדיסקורד. התפריטים ב-Hypixel עשויים להשתנות; הבוט לא תלוי בהם, רק בשדה שנשמר בפרופיל.

## מגבלות (חשוב להכיר)
- **הערך בפרופיל הוא טקסט חופשי.** Hypixel לא מוודא שהשם שייך לדיסקורד של השחקן. ההוכחה היא: "מי ששולט בחשבון ה-Hypixel כתב את שם המשתמש הזה". זה מספיק כדי שאף אחד לא יתבע חשבון של אחר, אבל זו לא הוכחה קריפטוגרפית.
- **שם משתמש שמשתחרר.** אם בעל חשבון Hypixel כתב שם דיסקורד, ואחר כך שינה/מחק את חשבון הדיסקורד, מישהו אחר יכול לקחת את השם הפנוי ולתבוע את החשבון. הסיכון קטן וקיים רק בחלון הזה. אם חשוד, צוות יכול לנתק עם `/unlink` ולבקש אימות מחדש.
- **נבדק ברגע האימות בלבד.** אם השחקן ישנה אחר כך את הפרופיל ב-Hypixel, הקישור בבוט נשאר. אין בדיקה חוזרת אוטומטית.
- **תלות בשירותים חיצוניים.** כש-Mojang/Hypixel לא זמינים, האימות נכשל (אף פעם לא "נפתח") והמשתמש מתבקש לנסות שוב; הכשל לא נספר נגדו. מגבלות קצב של Mojang לפי IP עלולות להשפיע בפריסה על IP משותף. הבוט מגביל את עצמו ל-20 קריאות ל-Hypixel בדקה כדי להגן על המפתח.
- **שחקן שלא נכנס מעולם ל-Hypixel או שהסתיר נתונים** לא יכול להתאמת.
- **חשבון אחד = משתמש דיסקורד אחד.** אם בעל חשבון איבד גישה לדיסקורד הישן שלו, צוות מנתק עם `/unlink ign:<שם>` והשחקן מאמת מחדש.
- **אלטרנטיבה חזקה יותר** (לא ממומשת): התחברות עם Microsoft/Xbox (OAuth) שמוכיחה בעלות על חשבון מיינקראפט ישירות, ללא תלות בהגדרות פרופיל. דורשת רישום אפליקציה ב-Azure ואישור לשימוש ב-API של Mojang, ולכן לא נבחרה כרגע.

## אבטחה
- ללא `HYPIXEL_API_KEY` לא ניתן לאמת (נכשל סגור).
- ההשוואה היא ל-username בלבד, ובהתאמה מלאה (לא `contains`). שם תצוגה אינו נבדק, כי כל אחד יכול לקבוע לעצמו שם תצוגה.
- 5 ניסיונות כושלים ב-15 דקות נועלים את המשתמש. כשלי שירות חיצוני לא נספרים.
- הקישור נכתב בטרנזקציה עם אילוצי UNIQUE על המשתמש ועל ה-UUID, כך שניסיונות מקבילים לא יוצרים שיוך כפול.
- המפתח נשלח ב-header ולא ב-URL, ולא נכתב ללוגים. כשהמפתח נדחה הצוות מקבל התראה בלוג המודרציה.

## בדיקה בשרת ניסיון
1. צרו שרת דיסקורד ריק לבדיקה, והזמינו אליו את הבוט.
2. `cp .env.example .env`, ומלאו טוקן, `CLIENT_ID`, `GUILD_ID`, `HYPIXEL_API_KEY`.
3. `npm run check:hypixel -- <שם_שלכם>` (בלי שם דיסקורד): ודאו שמופיע `Hypixel API: המפתח התקבל` ושהשדה Discord מוצג כ-`(לא מוגדר)`.
4. ב-Hypixel הגדירו את שם המשתמש שלכם בדיסקורד, חכו דקה, והריצו שוב עם שם הדיסקורד: `npm run check:hypixel -- <שם> <דיסקורד>`. צריך לראות `התאמה: כן`.
5. `npm start`, ואז `/setup role` (מאומת/לא מאומת) ו-`/verifypanel`.
6. **מקרה שלילי:** מחשבון דיסקורד שני נסו לאמת את אותו שם. צריך להיכשל ("מוגדר Discord אחר").
7. **מקרה חיובי:** מהחשבון שלכם לחצו על הכפתור. אמורים לקבל רול מאומת וכינוי. `/whois` מציג את הקישור.
8. הפעילו מחדש את הבוט ולחצו שוב על הכפתור הישן: אמור לענות "כבר אומת" ולא להיכשל.
9. `/unlink` ובדקו שהרולים חוזרים למצב לא-מאומת.
